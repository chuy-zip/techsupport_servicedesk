# Documentación

* **`service-desk.md`.** Reglas del servicio, qué puede hacer cada rol, cómo está armado y qué falta. Empezar por aquí.
* **`casos-de-uso.md`.** Escenarios comprobados por rol, incluidos los que deben fallar, y el recorrido con los datos de demostración.
* **`modelo-de-datos.md`.** Diagrama de las tablas y las decisiones del modelo.
* **`infraestructura.md`.** Entornos, variables, cómo correr en local, usuarios y datos de demostración, y la base de datos.
* **`ci-cd.md`.** Pipeline, protección de `main` y cómo se trabaja con pull requests.
* **`guia-de-estilo.md`.** Colores, tipografía, componentes y cómo se escriben los estilos.
